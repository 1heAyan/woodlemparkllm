Interactive User Functionality Flows

Step-by-step guides showing how users perform every task in the application

TEACHER DASHBOARD Record Behavior Incident & Point Deduction
Click "Record Incident" on Homeroom Roster
Select Student
  • Open searchable CustomSelect
  • Search by name or admission number
  • Shows: "Adm: 11771 • Grade 12-M"
  • Displays current score (Baseline: 80)
Select Violation Category
  • Disruptive Behavior (Rec: -4 pts)
  • Coming Late to Class (Rec: -2 pts)
  • Failing to Follow School Rules (Rec: -5 pts)
  • Neglect of Homework / Classwork (Rec: -3 pts)
  • Uniform / Dress Code Violation (Rec: -2 pts)
  • Disrespect to Staff or Peers (Rec: -6 pts)
  • Academic Dishonesty (Rec: -10 pts)
  • Other (Type custom violation title)
Specify Points & Restorative Action
  • Click quick button (-2, -4, -5, -10) or type
  • Live Preview: Current (80) → Projected (76)
  • Live Tier: Exemplary • Good • Critical
  • Action: Verbal Warning, Parent Notified, Detention, Counselor Referral
  • Type detailed teacher observation notes
80-Point Rubric
Click "Confirm & Deduct Points"
✓ Completed
Score reduced • Student/Parent alerted
TEACHER DASHBOARD Daily Homeroom Attendance Roll Call
Open Homeroom Advisory → Attendance Tab
Review Gate Arrival Flags
  • Inspect campus gate duty arrivals
  • Students with late slips automatically flagged
  • Approved parent leaves pre-populated
Mark Roll Call for Each Student
  • Present (Default green checkmark)
  • Authorized Absent (Verified illness/leave)
  • Unauthorized Absent (Unexcused)
  • Click "Mark All Present" shortcut if all are in
Click "Submit Today's Attendance"
✓ Completed
Roster saved • Absence SMS/App alerts sent
TEACHER DASHBOARD Author & Publish Online Quiz / Exam
Click "Create New Assessment" in Course View
Configure Exam Settings
  • Enter Title (e.g. "Chapter 4 Thermodynamics Quiz")
  • Select Target Class Sections (e.g. 12-A, 12-B)
  • Set Duration Countdown (e.g. 45 mins)
  • Set Availability Window & Hard Deadline
Add Exam Questions
  • Option 1: MCQ Question
    • Type prompt, add 4 options, click correct radio
  • Option 2: Text / Essay Question
    • Type prompt, add model answer & max points
  • Total marks auto-calculate in real time
Click "Publish Assessment to Students"
✓ Completed
Live on student exam portals
TEACHER DASHBOARD Official Assessment Term Mark Entry
Click "Term Mark Entry" on Class Dashboard
Select Assessment Term
  • Choose active term (e.g. "Term 1 Board Exam")
  • System loads grading window status (Open)
  • Displays enrolled class students table
Enter Student Component Marks
  • Theory Paper (Max: 70)
  • Practical Lab (Max: 20)
  • Viva / Project (Max: 10)
  • System blocks values exceeding component max
  • Total (100) & Percentage auto-compute
Click "Save & Submit Grades"
✓ Completed
Grades locked • Report cards ready
STUDENT DASHBOARD Taking an Online Exam / Quiz
Click "Start Assessment" on Exam Card
Review Instructions & Rules
  • Total questions count & maximum marks
  • Time limit countdown alert
  • Click "Begin Test" → Fullscreen exam launches
Answer Questions Under Live Timer
  • Timer counts down in sticky top bar
  • For MCQs: Click single choice option
  • For Text: Type detailed response in text box
  • Answers auto-saved continuously as you type
  • Use Question Palette to jump or flag for review
Click "Submit Assessment" (or timer expires)
✓ Completed
Instant score for MCQs • Sent for grading
STUDENT DASHBOARD Solve Coding Challenge in CS Lab
Click "CS Coding Lab" → Select Problem
Read Problem & Open Code Editor
  • Inspect task prompt, inputs, and constraints
  • Review sample inputs & expected outputs
  • Open Monaco in-browser IDE (Python 3 environment)
Write & Run Code Against Tests
  • Type solution in code editor
  • Click "Run Code" → In-browser compiler executes
  • Terminal outputs stdout, stderr, and run duration
  • View Sample Test Cases: Passed (Green) / Failed (Red)
Click "Submit Solution for Evaluation"
✓ Completed
Hidden test cases validated • Grade stored
PARENT DASHBOARD Multi-Child Sibling Switcher & Monitoring
Login via Verified Parent Credentials
Toggle Sibling Selector
  • Click top Sibling Switcher pills
  • e.g. Switch between "Ayaan (12-M)" • "Sara (8-A)"
  • Instant context switch without re-logging in
Inspect Live Child Standing
  • Today's attendance roll call status (Present / Absent)
  • 80-Point Conduct gauge & incident log breakdown
  • Teacher announcements & homework deadlines
✓ Completed
Full guardian oversight active
PARENT DASHBOARD Apply for Student Absence Leave
Click "Apply for Leave" on Attendance Tab
Fill Leave Request Form
  • Select Leave Category: Medical, Emergency, Travel
  • Pick Start Date & End Date range
  • Type explanation / reason for absence
  • Attach Doctor's note or medical certificate (PDF/Img)
Click "Submit Leave Request"
Class Teacher Review & Sync
  • Teacher reviews application on Homeroom dashboard
  • Teacher clicks "Approve Leave"
  • Attendance automatically updated to "Authorized Absent"
✓ Completed
Leave approved • Attendance cleared
ADMIN DASHBOARD Onboarding Student / Teacher User Profile
Click "Add New Profile" in User Directory
Enter Profile Information
  • Select Role: Student, Teacher, Parent, Staff
  • Enter Full Name, Email, and Phone
  • If Student: Admission No, Grade (1-12), Section (A-Z)
  • If Teacher: Assign Homeroom section & Course subjects
Generate Credentials & Badges
  • System issues unique Woodlem User Code
  • Set custom password or auto-generate secure PIN
  • Upload student ID photo avatar
Click "Save & Activate Account"
✓ Completed
User active • Login credentials issued
CAMPUS SECURITY Gate Duty Late Arrival Logging
Open Gate Scanner Terminal on Tablet
Identify Arriving Person
  • Scan physical student RFID / barcode badge
  • Or quick search by Admission No or Name
  • Profile card pops up with student photo & homeroom
Select Reason & Timestamp
  • Select Reason Preset:
    • School Bus Delayed
    • Heavy Traffic Congestion
    • Medical / Clinic Appointment
    • Unexcused Late Arrival
  • Exact time captured automatically (e.g. 08:14 AM)
  • Input optional officer notes or transport badge
Click "Issue Gate Pass & Log Arrival"
✓ Completed
Pass generated • Homeroom teacher alerted
