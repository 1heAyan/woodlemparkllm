How All Accounts Connect During Onboarding

In Woodlem LMS, accounts are not created in isolation. Enrolling a Student automatically triggers parent sibling binding, homeroom roll-call assignment, course enrollments, an 80-point behavior conduct ledger, and campus gate arrival badge issuance.

👨‍👩‍👧 Student ↔ Parent (Linked via Guardian Email & Sibling Switcher)
👩‍🏫 Student ↔ Class Teacher (Linked via Grade & Section for 80-Pt Conduct)
📚 Student ↔ Subject Teachers (Linked via Course Sections & Exams)
🛡️ Student ↔ Gate Duty (Linked via Admission RFID & Late Slips)
STUDENT ONBOARDING Student Admission & Automatic Linking
Admissions Officer Inputs Student Profile
Step 1: Enter Student Identity
  • Full Legal Name
  • School Student Email
  • Admission Number (e.g. 11771)
  • Grade (1 to 12) & Section (e.g. 12-M)
  • House Assignment (Emerald, Ruby, Sapphire, Amber)
Step 2: Bind Guardian Contact
  • Enter Guardian / Parent Email
  • Enter Guardian Emergency Mobile Phone
  • Specify Relationship (Mother, Father, Guardian)
→ Triggers Parent Engine
System Executes 4-Way Auto Linking
Step 3: Automated Interconnections
  • Parent Linking:
    • If Parent exists: Appends student to Parent's Sibling Switcher
    • If New Parent: Auto-creates Parent Account & credentials
  • Homeroom Teacher Linking:
    • Enrolls in Grade 12-M Homeroom Advisory
    • Initializes 80-Point Behavior baseline score
    • Adds to daily attendance roll-call register
  • Subject Courses Linking:
    • Enrolls in Grade 12 Physics, CS, Math sections
  • Gate Duty Security Linking:
    • Issues Student RFID / Barcode Badge for gate scans
Instant 4-Way Sync
Step 4: Generate Credentials
  • Issues unique Woodlem User Code
  • Generates initial password (e.g. woodlem123)
  • Uploads student ID photo avatar
✓ Completed
Student live across all 4 portals
